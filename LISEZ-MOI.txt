VERSION KAPPS STYLE

Cette version ajoute :
- un fond sombre semi-transparent inspiré des overlays Kapps ;
- un léger flou type verre ;
- une fine bordure ;
- des coins arrondis ;
- une ombre discrète ;
- le changement de sponsor toutes les 5 secondes.

Mise à jour sur GitHub :
1. Ouvre ton dépôt carrousselsponsorssv.
2. Clique sur Add file > Upload files.
3. Envoie tous les fichiers de cette archive.
4. GitHub signalera que index.html existe déjà : remplace-le.
5. Clique sur Commit changes.
6. Patiente environ 30 secondes, puis recharge :
   https://chrismotorsport.github.io/carrousselsponsorssv/

Si Kapps garde l'ancienne version :
- ferme et rouvre la Browser App ;
- ou ajoute temporairement ?v=2 à la fin de l'URL.
